Lucky Lotto 수정본

이 폴더의 파일을 기존 프로젝트 루트에 복사하고 Git 커밋/푸시하여 Vercel에 배포하세요. 기존 파일은 먼저 백업하세요. 이 패키지는 실제 사이트에 배포되지 않았습니다.

index.html, main.js, style.css를 함께 교체하고 나머지 HTML, ads.txt, robots.txt, sitemap.xml, vercel.json도 추가하세요. 기존 동물상 테스트 파일은 삭제하지 않았으며 이 패키지 메뉴에서는 연결하지 않습니다. 기존 다른 페이지가 있으면 정책, 탐색과 링크를 함께 검토하세요.

사이트 주소를 변경했다면 robots.txt와 sitemap.xml의 도메인도 실제 주소로 변경하세요.

배포 전 운영자 이메일, 문의 보존기간과 개인정보 처리 내용을 실제 운영 방식과 대조하고 Formspree 수신, Disqus 댓글 작성을 직접 확인하세요. 외부 서비스 연결 성공까지 검증한 것은 아닙니다. 광고 식별자는 첨부본 값을 유지했습니다. 유럽경제지역/영국/스위스 대상 광고를 제공할 경우 Google의 사용자 동의 정책에 맞춰 인증 CMP 등 요구사항을 설정하세요. 기본 코드 자체에는 지역별 동의 관리가 구현되지 않았습니다.

배포 후 /ads.txt, /sitemap.xml, /privacy.html과 모바일 화면을 확인하고 실제 애드센스 계정에서 사이트 연결/심사를 신청하세요. ads.txt는 승인 보장 수단이 아닙니다. 개인정보방침/이용안내/404 페이지에는 광고 코드를 넣지 않았습니다. 홈/가이드에 기존 AdSense 자동 광고 스크립트를 유지했으므로 실제 자동 광고 위치는 계정에서 확인하세요.

Google 품질 안내에 맞춰 관련 없는 메뉴, 과장된 당첨 유도 문구, 생성기와 무관한 장식을 줄이고 자체 계산 예시를 추가했습니다. 글 개수나 분량, 메타 태그만으로 승인이 결정되지 않습니다. 승인이나 광고 수익은 보장되지 않습니다.
